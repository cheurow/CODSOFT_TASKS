# CODSOFT

##### This repository has the results of tasks given during the CODSOFT Internship



🚢 Task 1: Titanic Survival Prediction 

In this project, I built a machine learning model to predict passenger survival on the Titanic. I used the Titanic dataset (downloaded from Kaggle, as per CodSoft's instructions for this task) and implemented Logistic Regression using Python and Scikit-Learn, training a binary classification model to predict whether a passenger survived or not based on features like passenger class and sex.
***
🎬 Task 2: Movie Rating Prediction 

In this project, I built a machine learning model to predict a movie's IMDb rating based on features like genre, director, and lead actors. I used the IMDb Movies India dataset and implemented a regression model using Python and Scikit-Learn, engineering features such as genre mean rating and encoded director/actor scores to predict the rating as a continuous value.

***
🌸 Task 3: IRIS Flower Classification 

In this project, I built a machine learning model to classify Iris flowers into their respective species. I used the Iris dataset (downloaded from Kaggle, as per CodSoft's instructions for this task) and implemented multiple classification algorithms using Python and Scikit-Learn, evaluating each model's accuracy to predict the flower species based on features like sepal length, sepal width, petal length, and petal width.
